# СКТО | Конькобежные расчёты

Одно устанавливаемое приложение (PWA) с общим главным меню и двумя **независимыми модулями**:

| Модуль | Папка | Ключ версии в `version.json` |
|---|---|---|
| Возрастные группы | `modules/age-groups/` | `ageGroups` |
| Разрядный калькулятор | `modules/ranks/` | `ranks` |

Название: «СКТО | Конькобежные расчёты». Под иконкой: «Расчёты СКТО».
Работает без интернета после первой загрузки, в том числе из подпапки GitHub Pages
(`https://имя.github.io/skto-calculators/`). Все пути относительные.

## Структура

```
index.html               главное меню, переходы, проверка обновлений, «О приложении»
manifest.webmanifest     манифест PWA
sw.js                    service worker (офлайн и кэши)
version.json             номера версий: оболочка и оба модуля
.nojekyll                чтобы GitHub Pages отдавал файлы как есть

modules/
  age-groups/
    index.html           весь код и данные «Возрастных групп»
    files.json           список файлов модуля (для офлайн-копии)
  ranks/
    index.html           весь код и нормативы «Разрядного калькулятора»
    files.json

icons/                   icon-192, icon-512, icon-maskable-512, apple-touch-icon, favicon
icon-source/             исходная квадратная картинка иконки
tools/make_icons.py      готовит все иконки из icon-source/icon-source.png
```

### Как устроена независимость модулей

* Каждый модуль — отдельный HTML-файл со своим JavaScript, который открывается в своём окне (`iframe`) внутри оболочки. Глобальные переменные и функции модулей **не пересекаются**: общего кода и общих нормативов нет, ничего не скопировано из одного в другой.
* Настройки хранятся в отдельных ключах `localStorage`:
  `skto-tools.age-groups.settings.v1`, `skto-tools.ranks.settings.v1`, `skto-tools.shell.settings.v1`.
* Офлайн-копия каждого модуля лежит в **своём** кэше: `skto-tools-mod-age-groups`, `skto-tools-mod-ranks` (оболочка — `skto-tools-shell`, иконки — `skto-tools-static`).
* Введённые значения не пропадают при переходе в главное меню и обратно: открытые модули остаются «живыми» до закрытия приложения.
* Приложение **не обращается** к данным «СКТО | Дневник конькобежца». Важно: все проекты на `имя.github.io` находятся на одном «origin», поэтому `sw.js` удаляет только кэши с префиксом `skto-tools-` и никогда не трогает чужие (проверено тестом: кэш, `localStorage` и IndexedDB «чужого» приложения остаются на месте).

### Что изменено в исходных модулях (всё остальное — байт в байт)

1. Разрядный калькулятор: ключ настроек `skto` → `skto-tools.ranks.settings.v1` с **однократным переносом** старых настроек (пол, категория катка, дистанция). Старый ключ `skto` **не удаляется**.
2. Разрядный калькулятор: кнопка внутри модуля «← Главное меню» переименована в «← Меню разрядов» (она возвращает во внутреннее меню модуля; «← Главное меню» теперь одна — в оболочке, сверху).
3. Возрастные группы: добавлено запоминание выбранного пола (ключ `skto-tools.age-groups.settings.v1`). Дата рождения не сохраняется.
4. Добавлен тег `theme-color`. Алгоритмы, нормативы и тексты не менялись.

## 1. Первая загрузка на GitHub Pages

1. На GitHub создайте репозиторий с именем `skto-calculators` (Public).
2. Распакуйте ZIP. Загрузите **содержимое** распакованной папки в корень репозитория (`Add file → Upload files`, перетащить все файлы и папки, включая скрытый `.nojekyll`). `index.html` должен лежать в корне репозитория, а не в подпапке.
3. `Commit changes`.
4. `Settings → Pages → Build and deployment`: Source — `Deploy from a branch`, Branch — `main`, папка `/ (root)` → `Save`.
5. Подождите 1–3 минуты (прогресс виден на вкладке `Actions`). Адрес: `https://имя.github.io/skto-calculators/`.
6. Откройте адрес, затем «О приложении · версии»: должно быть «Офлайн-копия: готова» и версии `1.0.0`.

Если загружаете через Git: `git add -A && git commit -m "release 1.0.0" && git push`.

## 2. Обновить «Возрастные группы»

Меняются **только** файлы в `modules/age-groups/`:

1. Замените `modules/age-groups/index.html` новой версией (и другие файлы папки, если они есть).
2. Если добавили новый файл в папку модуля — впишите его имя в `modules/age-groups/files.json` (поле `files`).
3. В `version.json` увеличьте `ageGroups` (например, `1.0.0` → `1.0.1`).
4. Загрузите на GitHub.

`sw.js`, `index.html`, `modules/ranks/` не трогаем.

## 3. Обновить «Разрядный калькулятор»

То же самое, но для `modules/ranks/` и ключа `ranks`:

1. Замените `modules/ranks/index.html` (и `files.json`, если менялся список файлов).
2. В `version.json` увеличьте `ranks`.
3. Загрузите на GitHub.

Нормативы живут внутри `modules/ranks/index.html` (блок `RAW`). Если меняете настройки или формат хранимых данных модуля, не меняйте имя ключа `skto-tools.ranks.settings.v1` без необходимости, иначе настройки пользователей сбросятся (при смене формата поднимайте суффикс `v2` и пишите перенос из `v1`).

## 4. Где менять номера версий

* **Модули:** только `version.json` — `ageGroups` и `ranks`.
* **Оболочка:** `app` в `version.json` **и** такой же номер в `index.html` в строке
  `<meta name="skto-app-version" content="1.0.0">`. Оба места должны совпадать.

Номер версии — любая строка, главное, чтобы она **отличалась** от прежней (по ней приложение узнаёт, что пора обновляться и показывает баннер). Рекомендуется формат `1.2.3`.

## 5. Обновить только оболочку или главное меню

1. Измените `index.html` (меню, тексты, оформление) и/или `manifest.webmanifest`, `icons/`.
2. Увеличьте `app` в `version.json` и номер в `<meta name="skto-app-version">` в `index.html`.
3. Загрузите на GitHub. Файлы модулей не меняются, их кэши не затрагиваются.

`sw.js` нужно менять **только** если:
* добавляется новый модуль (добавить его в `MODULE_IDS` в `sw.js` и в `MODULES` в `index.html`);
* меняется список файлов оболочки или иконок (`SHELL_FILES`, `STATIC_FILES`).

Менять номер кэша в `sw.js` для обычных обновлений не нужно: кэши не привязаны к версиям.

## 6. Как проверить, что пользователям пришло обновление

* Приложение проверяет `version.json` при запуске, при возвращении в приложение, при появлении сети и раз в 30 минут. Если номер изменился, сверху появляется полоса «Доступно обновление…» и кнопка «Обновить». Обновление модуля перезагружает **только этот модуль**; второй не перезагружается и его введённые значения остаются.
* Офлайн-копия обновлённого модуля скачивается в фоне сразу после проверки, ещё до нажатия «Обновить».
* Вручную: `Главное меню → О приложении → Проверить обновления`. Там же видны версии оболочки и модулей и состояние офлайн-копии.
* После `git push` сайт обновляется с задержкой 1–10 минут (смотрите `Actions`). Если только что выложили, а баннера нет — подождите и нажмите «Проверить обновления».
* Если во время скачивания пропала связь или файл не скачался, старая рабочая офлайн-копия остаётся нетронутой (обновление записывается только после успешной загрузки всех файлов модуля).

## 7. Какие файлы нельзя удалять

Обязательны: `index.html`, `manifest.webmanifest`, `sw.js`, `version.json`, `.nojekyll`,
`modules/age-groups/index.html`, `modules/age-groups/files.json`,
`modules/ranks/index.html`, `modules/ranks/files.json`,
все пять файлов в `icons/`.

Если удалить файл, перечисленный в `sw.js` или `files.json`, установка офлайн-копии завершится ошибкой и приложение будет работать только онлайн. Папки `tools/`, `icon-source/` и этот `README.md` сайту не нужны, их можно удалить из репозитория.

## 8. Как откатиться к предыдущей версии

1. На GitHub откройте нужный файл → `History` → найдите прежний коммит → `Revert` (или откройте старую версию файла, скопируйте её и сохраните как новую). Либо загрузите файлы из сохранённого ZIP предыдущего релиза.
2. Откатывайте только файлы нужного модуля.
3. **Поставьте в `version.json` новый, более высокий номер** (например, было `1.0.2` с ошибкой, откатили код — укажите `1.0.3`). Если вернуть старый номер `1.0.1`, у тех, у кого уже стоит `1.0.1`, баннер не появится, хотя код при следующем открытии модуля всё равно подтянется (модули загружаются сначала из сети).
4. Загрузите на GitHub и проверьте через «О приложении».

Рекомендуем перед каждым релизом сохранять ZIP предыдущей рабочей версии.

## 9. Как проверить приложение на iPhone и Android

**iPhone (Safari 16+):**
1. Откройте `https://имя.github.io/skto-calculators/` в Safari. Откройте оба модуля, затем «О приложении» (должно быть «Офлайн-копия: готова»).
2. «Поделиться» → «На экран „Домой“». Название под иконкой: «Расчёты СКТО».
3. Запустите с главного экрана: должно открыться без адресной строки, ничего не должно заходить под вырез и «домашнюю полоску».
4. Включите авиарежим и снова запустите: меню и оба модуля должны работать.
5. Поверните телефон в горизонтальное положение.

**Android (Chrome):**
1. Откройте адрес в Chrome, подождите пару секунд. Меню ⋮ → «Установить приложение» (или нажмите «Установить» на главной странице приложения).
2. Проверьте, что иконка не обрезана (круг/«капля»/квадрат с закруглением). Все значки внутри безопасной зоны.
3. Откройте установленное приложение, включите режим полёта, закройте и откройте снова — всё должно работать.
4. Долгое нажатие на иконку показывает быстрые действия «Возрастные группы» и «Разрядный калькулятор».
5. Кнопка «Назад» на Android из модуля возвращает в главное меню.

**Проверка обновления:** выложите тестовую версию (например, добавьте пробел в `modules/ranks/index.html` и поднимите `ranks`), откройте установленное приложение при включённом интернете — через несколько секунд появится полоса «Доступно обновление: «Разрядный калькулятор»».

## Иконки

Исходная картинка лежит в `icon-source/icon-source.png`. **Сейчас там временная заглушка**: если нужна ваша готовая иконка — замените этот файл (квадратный PNG, лучше 1024×1024 и больше) и выполните:

```
pip install pillow
python3 tools/make_icons.py icon-source/icon-source.png
```

Скрипт без добавления надписей создаёт все пять файлов в `icons/`. Для `icon-maskable-512.png` картинка уменьшается до 78% со сплошными полями цвета краёв, поэтому конёк, секундомер и календарь не обрезаются на Android (при необходимости доля задаётся константой `MASKABLE_SCALE`). После замены иконок увеличьте `app` в `version.json` и в `index.html`. На телефонах уже установленное приложение может сменить иконку только после переустановки, это ограничение ОС.

## Если что-то пошло не так

* Открывайте приложение по `https://`: service worker и установка не работают с `file://` и в некоторых встроенных браузерах (Telegram и т.п.). Откройте ссылку в Safari или Chrome.
* «Офлайн-копия: неполная/недоступна» в «О приложении» — откройте приложение при подключении к интернету и обновите страницу.
* Сбросить локальную копию: удалите приложение с главного экрана и откройте адрес заново (настройки калькуляторов при этом очистятся только если очистить данные сайта).

## Смена иконки у пользователей (ревизия 2)

Иконки подключены с `?v=2` (манифест, favicon, apple-touch-icon) и ревизией в `sw.js`. Чтобы снова сменить иконку: замените PNG в `icons/`, увеличьте `?v=2` → `?v=3` в `manifest.webmanifest` и `index.html` и поправьте число в комментарии «Ревизия иконок» в `sw.js`. На iPhone иконка уже установленного ярлыка не обновляется сама: ярлык нужно удалить и добавить заново.
